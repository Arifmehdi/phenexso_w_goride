 HOW TO CHECK EACH SIDE (step by step)
================================================================================

 PRE-REQ (once): Laragon running (Apache + MySQL). Point the Flutter app at
 your server in lib/services/api_service.dart (currentEnv). Rebuild: flutter run.

 ── [WEB] Web admin panel ──
   Log in: http://localhost/goride/public/login  (admin account)
   Then check:
     05,13  Ride status/history .. /admin/ride-matching  &  dashboard "Recent Rides"
     18     Per-km fare .......... /admin/websiteparam  (per_km_rate field)
     21     Commission % ......... /admin/websiteparam  (commission_rate)
     22     Promo codes .......... /admin/promo-codes   (add TEST10 → apply in app)
     23     Banners .............. /admin/banners       (upload → app home shows it)
     29,32  Driver verify ........ /admin/drivers  &  /admin/approvals
     30     Vehicles ............. /admin/vehicles
     33     SOS alerts ........... /admin/sos/alerts  (list of triggered SOS)
     01,02  Online drivers / live  /admin/dashboard KPIs  &  /admin/live-rides

 ── [API] Laravel API (no screen needed) ──
   1) Get a token:
      curl -X POST http://localhost/goride/public/api/login \
           -H "Accept: application/json" -d "login=EMAIL" -d "password=PASS"
   2) Call endpoints with -H "Authorization: Bearer TOKEN":
      02  /api/ride-requests/match         13  /api/ride-history
      09  /api/ride-requests/{id}/payment  20  /api/wallet/balance
      18  /api/website-parameters          24  /api/driver/earnings
      27  /api/ride-requests/{id}/receipt  31  /api/driver/stats
      28  /api/driver-ratings              19  /api/rider-ratings
      33  /api/sos/trigger                 30  /api/admin/vehicles

 ── [APP] Flutter app (use TWO phones: 1 passenger, 1 driver) ──
   DRIVER phone: register as driver → verify docs → admin approves →
     go Online (01) → wait for the ride call (02, 07) → Accept →
     "Go to passenger" + NAVIGATE (04) → I've Arrived → Start Trip →
     Complete → rate passenger (19).
   PASSENGER phone: register (apply a promo, 22) → book ride → get matched →
     land on live tracking → chat/call driver (03) → after complete, choose
     payment: Cash/Wallet/Card/Split (09,11,12,20,21) → get receipt (27) →
     rate driver (28) → check Ride History (13,25) & Wallet (20).
   Push (06,07,08,26): background the driver app / lock the screen, then have
     the passenger book — a full-screen ride call should ring. If not, on the
     driver phone disable battery optimization for GoRide.

 ── [FADM] Flutter in-app admin area ──
   Log in as admin in the app → Admin panel. Check the cards:
     User Management (approvals + driver verify, 29,32)
     Vehicle Management (30) · Live Rides (02,05) · Reports · Payouts ·
     Support · Surge · System Settings (commission %, 21) · Banners (23)
   Every card should show live DB data with working buttons.

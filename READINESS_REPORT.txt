 4. HOW TO TEST THE FULL PASSENGER + DRIVER FLOW (two phones/emulators)
--------------------------------------------------------------------------------
 You need two devices (or one emulator + one phone): one as PASSENGER,
 one as DRIVER.

 DRIVER side (device A):
  1. Register with role "driver" (Join as Rider/Driver). Account is created
     PENDING — the app takes you to the verification screens: upload NID,
     driving licence, vehicle info, photo.
  2. Approve the driver as admin: log into the Laravel admin panel
     (http://localhost/goride/public) or call
     POST /api/admin/users/{id}/approve-reject {"action":"approve"}.
  3. Log in on the app → Driver Dashboard → toggle ONLINE (top-right).
     The app starts sending GPS to Firestore + Laravel every few seconds.
  4. Wait for a ride call.

 PASSENGER side (device B):
  1. Register (default role) — active immediately, no approval needed.
     OTP NOTE: SMS is not connected; the OTP code is written to
     goride\storage\logs\laravel.log — search for "OTP for".
  2. Home > choose service (Car/Bike/CNG...) > set pickup & destination
     (map picker or search box) > see the fare estimate > confirm.
  3. The request is written to Firestore; every online driver within 5 km
     gets the ride-call screen (popup + sound if app open; FCM push if
     backgrounded and step 3.3 was done).

 THE TRIP:
  - Driver taps ACCEPT (first driver to accept wins — atomic claim).
  - Driver screen: "Go to the passenger" navigation view — pickup address
    card, NAVIGATE button (opens Google Maps turn-by-turn), passenger icon
    marker on the map. Tap the ▲ arrow for full details (fare, chat, call,
    cancel).
  - Driver taps I'VE ARRIVED → passenger sees "Driver has arrived".
  - Driver taps START TRIP → live tracking to destination for both sides.
  - Driver taps COMPLETE TRIP.
  - Passenger picks payment: Cash / Wallet / Card (SSLCommerz sandbox).
  - Both sides get the rating screen (stars + tags + review).
  - Trip appears in Ride History; a PDF receipt is available; driver
    earnings/stats update.

 EXTRAS you can also test: SOS button (passenger, during trip),
 share-trip link (public live map page), in-app chat between driver and
 passenger, wallet top-up, promo codes, saved addresses, support tickets
 (sidebar > Help & Support).
